Change: Clear message when the server requires two-factor authentication

When the server requires two-factor authentication for an account that signs
in with a user name and password, it rejects even the correct password. The
client said "The user name or password is not correct." and asked again and
again. It now says that the server requires two-factor authentication and how
to go on: enter an app password from the web interface (Settings → Security),
or remove the account and add it again to sign in in the browser.
